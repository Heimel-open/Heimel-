# HEIMEL public agent boundary

This repository is the frozen public HEIMEL surface.

Do not extend it with post-freeze private VALO work.

Hard rules:
- No new product features.
- No private runtime architecture.
- No Synapse or distributed-intelligence research.
- No GAUTE mechanism, recipe, dimensions, carrier details or substitution logic.
- No relational-state/history mechanism, holonomy mechanism, private provenance architecture, ACE/continuity layer, or other proprietary post-freeze architecture.
- Do not infer that later private work is the next public HEIMEL version.
- Do not rename private VALO/Synapse/GAUTE work as HEIMEL public work.

Permitted changes are limited to:
- external conformance;
- necessary correction of the existing public contract;
- concrete falsification of an existing public claim;
- security or semantic defect correction.

Any expansion beyond this boundary requires an explicit human decision that the public freeze is being changed. Repository activity, private implementation, research results, tests, issues, PRs or agent proposals do not constitute that decision.

`PUBLIC_BOUNDARY.json` is authoritative for the machine-readable public/private boundary.
